# LinkedIn Post Draft

I completed my Week 2 portfolio project for ITEP 414 – System Administration and Maintenance: an Enterprise Infrastructure Plan for a fictional 20-person software startup, ABC Startup Solutions.

The project challenged me to turn business requirements into a practical technical design. I prepared hardware, software, and networking inventories; created a segmented enterprise network topology; compared key system administration roles; and proposed backup, endpoint security, password, internet, server, and expansion strategies.

One of my main takeaways is that infrastructure planning is not simply choosing equipment. Each decision should support how people work, protect business data, remain manageable, and leave room for growth. Designing separate VLANs for IT, HR, Finance, Sales, servers, and guests helped me see how network structure supports both operations and security.
